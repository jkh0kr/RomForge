# Switch - 리팩

Switch 게임 파일을 관리하고 언팩/리팩하는 탭입니다. 여러 타이틀을 한 번에 다룰 수 있으며, 본편/업데이트는 자동으로 최신 것으로 교체되고 DLC는 계속 추가됩니다.

지원 입력 형식: NSP, NSZ, XCI, XCZ

## 화면 구성

탭이 **파일**과 **설정** 두 개로 나뉩니다.

### 파일 탭

- **타이틀 목록** — 종류, 타이틀(아이콘/이름/타이틀ID), 버전, 한글패치, 확장자, 크기가 표시됩니다.
    - 게임 파일이나 폴더를 목록에 드래그 앤 드롭하면 추가됩니다.
    - 목록에서 우클릭하면 **폴더 열기**, **한글패치 취소**, **선택 삭제**, **전체 삭제** 메뉴를 사용할 수 있습니다.
    - 각 타이틀의 **한글패치** 칸을 클릭하거나 드래그하면 한글패치를 지정할 수 있습니다. 클릭하면 **폴더 선택...**, **압축파일 선택(zip/7z)...** 메뉴로 지정할 수도 있습니다.
- 오른쪽 버튼 — **파일 추가**, **폴더 추가**, **한글패치 일괄 지정**(클릭 시 **폴더에서 찾기...** / **압축파일에서 찾기(zip/7z)...** 선택 가능, title ID 기준으로 자동 매칭), **선택 삭제**, **전체 삭제**, **도움말**

### 설정 탭

- **지원 언어 목록** — 체크된 언어만 사용 가능하며, 체크 해제 시 강제로 비활성화됩니다.
- **커버 이미지** — PNG, JPG, GIF, BMP, WEBP 지원. 드래그 앤 드롭으로 설정, 반대로 드래그하면 추출됩니다.
- **타이틀명**
- **변경할 Title ID** — 16자리 16진수(예: `0100000000010000`)로 입력합니다. 비워두면 원본 Title ID가 그대로 유지됩니다.
- **배급사**
- **멀티롬 인덱스** — 하나의 NSP 안에 여러 게임이 들어 있는 경우, 인덱스를 지정한 뒤 리팩하면 해당 인덱스의 게임만 별도 NSP로 만들 수 있습니다.
- **강제 언어 설정 / 강제 언어 취소** — 강제 언어 설정을 적용하면 선택한 언어만 남기고 나머지는 전부 비활성화됩니다.

### 공통

- **작업 폴더**
- **언팩 / 리팩 / 언팩 + 리팩(Full)** 버튼
- **진행률** — 진행률, 속도, 경과 시간

## 사용 방법

한글패치 배포 방식에 따라 크게 2가지 케이스로 나뉩니다.

### 케이스 1) 일반적인 덮어쓰기 패치 (대부분의 한글패치)

`romfs`, `exefs` 폴더가 그대로 들어있는, 원본 파일을 통째로 교체하는 방식의 한글패치입니다. 대부분의 Switch 한글패치가 이 케이스입니다.

1. 게임 파일(본편/업데이트/DLC)을 목록에 드래그 앤 드롭합니다. 본편/업데이트는 자동으로 최신 버전으로 교체되고, DLC는 계속 추가됩니다.
2. 한글패치 칸에 패치 폴더 또는 zip/7z 압축파일을 그대로 지정합니다. 압축을 미리 풀 필요는 없습니다. 여러 타이틀에 한꺼번에 적용하려면 **한글패치 일괄 지정** 버튼을 사용하세요.
3. 필요하면 **설정** 탭에서 언어, 커버 이미지, 타이틀명, 배급사, Title ID, 멀티롬 인덱스, 강제 언어 설정을 조정합니다.
4. **작업 폴더**를 지정합니다.
5. **언팩**, **리팩**, 또는 **언팩 + 리팩(Full)** 중 상황에 맞는 것을 실행합니다.

### 케이스 2) xdelta 패치

한글패치가 `abc.xdelta`처럼 diff 기반 파일로 배포되는 경우입니다.

패치 폴더(또는 압축파일)에 `abc.xdelta`가 있으면, `romfs` 안의 `abc.*` 전체 파일을 대상으로 패치를 시도합니다. 원본과 정확히 일치하지 않는 파일은 자동으로 무시되고, 일치하는 파일만 패치됩니다. `romfs`, `exefs` 같은 세부 폴더 구조를 맞출 필요 없이 루트에 두어도 하위 전 폴더를 뒤져서 알아서 찾아 패치합니다.

나머지 진행 방법은 케이스 1과 동일합니다.
