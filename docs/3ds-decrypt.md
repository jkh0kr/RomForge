# 3DS - 복호화

3DS용 롬 파일을 복호화하는 탭입니다.

!!! danger "키셋 필수"
    이 기능은 3DS 키셋이 반드시 있어야 동작합니다. 키셋 구하는 방법은 [실행 및 키파일 설정](installation.md)을 참고하세요.

## 화면 구성

1. **게임 파일 리스트**
2. **파일 추가** — 여러 개 동시 지정 가능
3. **폴더 추가**
4. **선택 삭제**
5. **전체 삭제**
6. **시작**
7. **취소**
8. **로그**

## 사용 예시

이미 복호화되어 있는 파일을 지정하면 자동으로 건너뛰고 진행됩니다. 즉, 복호화된 파일과 암호화된 파일이 섞여 있어도 상관없이 한꺼번에 넣고 돌리면, 암호화된 파일만 골라서 복호화합니다.
