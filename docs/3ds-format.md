# 3DS - 포맷 변환

3DS용 포맷 변환 기능입니다. 3DS, CCI, CIA, ZCCI 형식을 상호 변환할 수 있습니다.

파일마다 개별적으로 출력 포맷을 지정해서 변환할 수 있습니다.

!!! danger "키셋 필수"
    이 기능은 3DS 키셋이 반드시 있어야 동작합니다. 키셋 구하는 방법은 [실행 및 키파일 설정](installation.md)을 참고하세요.

## 화면 구성

1. **게임 파일 리스트**
2. **파일 추가** — 여러 개 동시 지정 가능
3. **폴더 추가**
4. **선택 삭제**
5. **전체 삭제**
6. **시작**
7. **취소**
8. **로그**
