# 3DS - 병합

게임 파일과 한글패치를 병합하는 탭입니다.

!!! danger "키셋 필수"
    이 기능은 3DS 키셋이 반드시 있어야 동작합니다. 키셋 구하는 방법은 [실행 및 키파일 설정](installation.md)을 참고하세요.

## 화면 구성

1. **롬 파일**
2. **한글패치 폴더** — `exefs`, `romfs` 폴더가 들어있는 상위 폴더를 지정합니다.
3. **작업 폴더** — 언팩 폴더이자, 결과 CCI 파일이 생성될 폴더
4. **언팩**
5. **리팩 (폴더 기반)** — 언팩해놓은 폴더를 패킹합니다.
6. **언팩 + 리팩 (메모리 기반)** — 폴더로 언패킹하지 않고 바로 메모리에서 패킹합니다. 불필요한 SSD 파일 I/O를 방지합니다.
7. **게임 정보**
8. **진행도**
9. **로그**

## 사용 예시

파일 지정(3DS, CCI, CIA 아무 형식이나 가능) → 한글 패치 폴더 지정 → **언팩 + 리팩**을 실행하면 됩니다.

!!! tip "언팩 + 리팩 (메모리 기반)을 쓰세요"
    이 방식은 물리 디스크에 언팩하지 않기 때문에 훨씬 빠릅니다. SSD 수명 보호와 속도, 둘 다 챙길 수 있어 이 방식을 우선 사용하는 것을 추천합니다.

암호화된 롬은 자동으로 복호화한 뒤 리팩이 진행됩니다. `code.ips` 같은 IPS 패치 파일이 있으면 자동으로 적용한 뒤 리팩하므로, IPS 패치를 수작업으로 미리 적용할 필요가 없습니다.
