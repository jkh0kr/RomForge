# PSP - 포맷 변환

PSP용 포맷 변환 기능입니다. ISO, CSO, CHD 형식을 상호 변환할 수 있습니다.

## 화면 구성

1. **게임 파일 리스트**
2. **파일 추가**
3. **폴더 추가**
4. **선택 삭제**
5. **전체 삭제**
6. **시작**
7. **취소**
8. **로그**

## 사용 예시

- CSO만 있는데 CHD로 바꾸고 싶을 때 사용하면 됩니다.
- CHD가 실기에서 인식되지 않을 때, 이 기능으로 다른 포맷으로 바꿔서 사용하면 됩니다.
