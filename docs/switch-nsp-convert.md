# Switch - 새턴롬 NSP 변환

새턴(SS) 게임 이미지를 Switch용 NSP 패키지로 변환하는 탭입니다.

## 화면 구성

1. **CUE 파일** — 변환할 새턴 게임의 CUE 파일 경로 (드래그 앤 드롭 가능)
2. **원본 NSP/NSZ 파일** — 베이스로 사용할 NSP 또는 NSZ 파일 (드래그 앤 드롭 가능)
3. **작업 폴더**
4. **커버 이미지** — PNG, JPG, GIF, BMP, WEBP 지원. 이미지 파일을 드래그 앤 드롭하면 적용됩니다.
5. **게임명**
6. **배급사**
7. **게임 ID** — 읽기 전용, CUE 파일에서 자동으로 채워집니다.
8. **버전** — 읽기 전용, CUE 파일에서 자동으로 채워집니다.
9. **설정**
   - **와이드 스크린** — 체크 시 와이드 스크린으로 출력
   - **사운드 볼륨** — 기본값 100%, 드롭다운으로 조절
10. **작업 시작** — 변환 진행 (진행률, 속도, 경과 시간, 진행바 표시)

## 사용 방법

1. **CUE 파일**(1번)에 변환할 새턴 게임의 CUE 파일을 지정합니다.
2. **원본 NSP/NSZ 파일**(2번)에 베이스로 사용할 NSP/NSZ 파일을 지정합니다.
3. **작업 폴더**(3번)를 지정합니다.
4. 게임 ID와 버전은 CUE 파일 정보를 기반으로 자동 입력됩니다. 게임명, 배급사, 커버 이미지를 원하는 대로 입력·설정합니다.
5. 필요하면 와이드 스크린, 사운드 볼륨 옵션을 설정합니다.
6. **작업 시작**을 눌러 변환을 진행합니다.
