# 패치 - 아케이드

꿀렁이 전용 아케이드 한글 패치를 진행하는 탭입니다.

## 화면 구성

- **원본 ZIP** — FBNeo용 ZIP 파일을 드래그 앤 드롭
- **패치(IPS/폴더/ZIP)** — IPS 파일, 폴더, 또는 ZIP 파일을 드래그 앤 드롭
- **패치 선택** — 등록된 패치 패키지 중에서 선택하는 드롭다운
- **매칭 목록** — ZIP 안의 각 게임 파일과 매칭된 패치 파일을 항목별로 보여주는 목록
    - 각 항목은 원본 파일명 → 패치 파일명, 매칭 상태(매칭/미매칭), 매칭 사유(예: CRC 일치), 항목별 진행률로 구성됩니다.
    - 항목의 패치 파일 칸에 다른 파일을 드래그 앤 드롭하면 해당 항목만 패치를 바꿀 수 있습니다.
    - 항목별 드롭다운으로 다른 패치 파일을 선택할 수도 있습니다.
- **전체 진행률** — 하단에 전체 진행 상황과 진행률 바로 표시됩니다.

## 사용 방법

1. 원본 ZIP과 패치(IPS/폴더/ZIP)를 각각 드래그 앤 드롭합니다. 확장자 기준으로 자동 매칭됩니다.
2. 매칭 목록에서 각 게임 항목이 제대로 매칭됐는지(매칭/미매칭) 확인합니다. 미매칭인 항목은 매칭 사유가 함께 표시됩니다.
3. 필요하면 항목별로 패치 파일을 드래그하거나 드롭다운에서 직접 지정해서 바꿀 수 있습니다.
4. **패치 시작**을 누르면 항목별로 순서대로 패치가 진행되며, 항목별/전체 진행률이 함께 표시됩니다.
