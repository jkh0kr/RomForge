# 변환

여러 플랫폼의 파일 포맷을 한 화면에서 변환할 수 있는 통합 변환 탭입니다.

## 변환 가능 조합

| 플랫폼 | 변환 |
| --- | --- |
| **Switch** | NSP ↔ XCI |
| **3DS** | CCI, 3DS ↔ CIA |
| **Wii U** | WUD, WUX, WUA → WUP, Loadiine, WUA |
| **CD Image** | MDF+MDS, CCD+IMG+SUB → BIN+CUE, ISO |
| **PSP** | PBP → BIN+CUE |

## 화면 구성

- **파일 목록** — No, 파일명, 입력 포맷, 출력 포맷(파일별 드롭다운으로 개별 지정), 진행률이 표시됩니다.
    - 파일이나 폴더를 목록에 드래그 앤 드롭하면 추가됩니다.
    - 목록에서 우클릭하면 **폴더 열기**, **선택 삭제**, **전체 삭제** 메뉴를 사용할 수 있습니다.
- **파일 추가 / 폴더 추가 / 선택 삭제 / 전체 삭제**
- **시작 / 취소**

## 사용 방법

1. 변환할 파일 또는 폴더를 목록에 드래그 앤 드롭합니다. 위 표에 해당하는 형식이면 자동으로 인식됩니다.
2. 각 파일의 **출력** 열에서 원하는 변환 포맷을 개별적으로 선택합니다.
3. **시작**을 눌러 변환을 진행합니다.

!!! tip "여러 플랫폼을 한 번에"
    Switch, 3DS, Wii U, CD, PSP 파일을 종류 구분 없이 한꺼번에 목록에 넣고 각자 원하는 포맷으로 지정한 뒤 한 번에 변환할 수 있습니다.
